# Rushed Crops — browser playtest

[Play Rushed Crops](https://ahmtb.github.io/rushedcrops-playtest/)

An early Unity WebGL playtest of Rushed Crops. Use a desktop browser with a keyboard and mouse. The game runs in the browser without an installation or account. Progress resets on reload.

| Control | Action |
| --- | --- |
| WASD / mouse | Move / look |
| Shift / Space | Sprint / jump |
| E | Pick up, interact, plant or harvest |
| 1–5 | Select a hotbar slot |
| Left click | Use the selected tool |
| Escape | Release the mouse and pause |

Use the Fullscreen button below the game to expand it. Press Play or Resume to capture the mouse again.

[Leave playtest feedback](https://github.com/AhmTb/rushedcrops-playtest/issues/new?title=Playtest%20feedback) — please include your browser, what you tried, and what happened. GitHub sign-in is required to submit an issue.

This repository contains the published browser build. The Unity source is maintained separately.
